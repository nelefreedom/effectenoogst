Effectenoogst - content creation experiments by Nele

12th November 2026.

These are concepts that I've created in the week that Claude Fable 5.2 was launched and I wanted to find out what it could do. This is what happened.

 I've given the machine my context to work with: all of my outcome harvesting materials, from theory to reports I've deveoped in the past. Also, I've given it my most recent proposal for the Initiatieven Collectief, a network of initiatives that support youth who sit at home, for an outcome harvesting (effectenoogst) assigment for Movisie.

The prompt was simply:
Use ElevenLabs to create cool, engaging, and high-quality products. You decide which products best suit what I offer. In any case, I want a dashboard. Use Perspectivity’s brand identity as a foundation, then get creative. Incorporate sub-agents. Make sure to use up as many ElevenLabs credits as possible.

The markdown files at the bottom contain the latest formulations. I tweaked the texts only once! The dashboard uses fictitious examples. Through ElevenLabs, Claude is suddenly able to generate voices, sounds, and images. Via GitHub, it can build and test a websites and apps, like this site.
